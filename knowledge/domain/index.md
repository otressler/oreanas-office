# Overview

- [Data model](data-model.md) - How the entities relate, and what changed from the original proposal

# Campaign and people

- [User](user.md) - A person who signs in; can be a player in one campaign and the DM in another
- [Registration invite](registration-invite.md) - A 4-hour link from the site admin that lets people create an account
- [Campaign](campaign.md) - A running game with members, sessions, characters and a bestiary
- [Campaign member](campaign-member.md) - Links a user to a campaign with a role
- [Character](character.md) - A player character owned by one user in one campaign
- [Session](session.md) - One game night with its own DM; at most one is active per campaign

# Fights

- [Encounter](encounter.md) - One fight: a battle map plus the tokens on it
- [Battle map](battle-map.md) - Grid layout (terrain, elevation, features, entrances), scene description and background image
- [Creature type](creature-type.md) - Reusable monster template with size and icon
- [Token](token.md) - A character or creature placed on an encounter's grid
- [Status](status.md) - Condition and custom status definitions, status lists, and the statuses set on tokens
- [Asset](asset.md) - A generated or uploaded image: map background or token icon
